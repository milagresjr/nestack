CLI NestJS para criar projetos com DDD e Prisma

O nestack gera uma aplicação NestJS já estruturada com arquitetura em camadas, Prisma com driver adapter, Zod, Swagger, Vitest e autenticação JWT opcional — e depois segue evoluindo esse projeto com geradores de código.

Começar Ver no GitHub

Instalação

Globalmente, ou direto pelo npx sem instalar nada: 

npm install -g nestack
npx nestack new meu-app

O que você já recebe pronto

Arquitetura em camadas

Uma estrutura domain / infra para seguir crescendo, e não um src/ solto.

Prisma com driver adapter

@prisma/adapter-pg — sem binário de engine no container.

Validação e documentação

Schemas Zod com validation pipe e Swagger já configurado.

Testes ligados

Vitest com configs unit e e2e, aliases e helpers de seed.

Auth JWT opcional

Tokens RS256, guard, strategy e o decorator @Public() — escolhido na criação.

Geradores

Entity, repository, use-case, controller, module, DTO, presenter, event ou um resource completo.

Quick start

  1. Crie o projeto: nestack new meu-app
  2. Suba o Postgres: docker compose up -d --wait
  3. Rode a migração: npx prisma migrate dev --name init
  4. Suba a API: npm run start:dev

A API sobe em http://localhost:3333 e o Swagger em http://localhost:3333/docs.

Comandos

Comando Descrição
nestack new <nome> [--yes] Cria um projeto Nest
nestack make:<tipo> <nome> Gera arquivo(s) com código base
nestack migrate [nome] Atalho para prisma migrate dev
nestack db:seed Atalho para prisma db seed

Tipos dos geradores: entity, repository, use-case, controller, module, dto, presenter, event, resource. 

nestack make:entity user -m forum
nestack make:use-case create-user -m forum
nestack make:resource user -m forum

Stack gerada

  • NestJS
  • Prisma + @prisma/adapter-pg
  • PostgreSQL
  • Zod (validação)
  • Swagger (documentação)
  • Vitest (testes)
  • bcryptjs (hash)
  • JWT RS256 opcional
